Thank you for your interest in the Avala Agents SDK!

## Reporting bugs & requesting features

Please [open an issue](https://github.com/avala-ai/avala-agents-python/issues) with:

- **Bugs**: Python version, SDK version (`pip show avala-agents`), minimal reproduction steps, and the full error traceback.
- **Feature requests**: A description of the use case and the API you'd like to see.

## About this repository

<Warning>
This repository is a **read-only mirror** of the SDK source code. The Avala team maintains the code internally and publishes updates here. Pull requests cannot be merged — please use issues for all feedback.
</Warning>

## Running tests locally

If you want to run tests locally to validate changes or explore the SDK:

```bash
pip install -e ".[dev]"
pytest -v
ruff check .
mypy avala_agents/
```

<Note>
Ensure you have Python 3.9 or higher installed before running local tests.
</Note>
