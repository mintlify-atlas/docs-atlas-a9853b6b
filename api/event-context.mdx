title: EventContext
description: Context object for dataset and export event handlers

## Overview

The `EventContext` dataclass is passed to handlers registered for dataset and export events. These events carry resource-level metadata rather than task or result data. Use the action methods to acknowledge or respond to these events.

## Attributes

<ResponseField name="execution_uid" type="str">
  Unique identifier for this agent execution.
</ResponseField>

<ResponseField name="event_type" type="str">
  The event type that triggered this execution (e.g., `"dataset.created"`, `"export.completed"`).
</ResponseField>

<ResponseField name="resource_uid" type="str | None">
  Unique identifier for the dataset or export resource that triggered this event.
</ResponseField>

<ResponseField name="resource_type" type="str | None">
  Type of resource (e.g., `"dataset"`, `"export"`).
</ResponseField>

<ResponseField name="project_uid" type="str | None">
  Unique identifier for the project this resource belongs to, if available.
</ResponseField>

<ResponseField name="payload" type="dict[str, Any]">
  Raw event payload containing all event-specific data. Structure varies by event type.
</ResponseField>

## Methods

### approve()

Approve this event execution.

```python
@agent.on("dataset.created")
def handle(context):
    context.approve("Dataset creation acknowledged")
```

#### Parameters

<ParamField path="reason" type="str" default='""'>
  Optional human-readable explanation for the approval.
</ParamField>

#### Raises

- `AgentActionError`: If the action submission fails.
- `AgentTimeoutError`: If the action submission times out.

### reject()

Reject this event execution.

```python
@agent.on("export.failed")
def handle(context):
    context.reject("Export failure requires investigation")
```

#### Parameters

<ParamField path="reason" type="str" default='""'>
  Human-readable explanation for the rejection.
</ParamField>

#### Raises

- `AgentActionError`: If the action submission fails.
- `AgentTimeoutError`: If the action submission times out.

### flag()

Flag this event execution for manual review.

```python
@agent.on("dataset.deleted")
def handle(context):
    context.flag("Dataset deletion requires verification")
```

#### Parameters

<ParamField path="reason" type="str" default='""'>
  Human-readable explanation for the reviewer.
</ParamField>

#### Raises

- `AgentActionError`: If the action submission fails.
- `AgentTimeoutError`: If the action submission times out.

### skip()

Acknowledge the execution without taking any workflow action.

```python
@agent.on("dataset.created")
def handle(context):
    print(f"Dataset {context.resource_uid} created")
    context.skip()
```

#### Raises

- `AgentActionError`: If the action submission fails.
- `AgentTimeoutError`: If the action submission times out.

## Usage Examples

### Dataset Creation Handler

```python
@agent.on("dataset.created")
def on_dataset_created(context):
    dataset_uid = context.resource_uid
    project_uid = context.project_uid
    
    print(f"New dataset {dataset_uid} created in project {project_uid}")
    
    # Access additional data from payload
    dataset_name = context.payload.get("dataset_name")
    print(f"Dataset name: {dataset_name}")
    
    context.skip()
```

### Export Completion Handler

```python
@agent.on("export.completed")
def on_export_complete(context):
    export_uid = context.resource_uid
    
    # Access export-specific data
    export_format = context.payload.get("export_format")
    file_url = context.payload.get("file_url")
    
    print(f"Export {export_uid} completed")
    print(f"Format: {export_format}")
    print(f"Download URL: {file_url}")
    
    context.approve("Export verified")
```

### Dataset Deletion Monitoring

```python
import logging

logger = logging.getLogger(__name__)

@agent.on("dataset.deleted")
def on_dataset_deleted(context):
    dataset_uid = context.resource_uid
    
    # Log deletion for audit trail
    logger.warning(
        "Dataset deleted",
        extra={
            "dataset_uid": dataset_uid,
            "project_uid": context.project_uid,
            "payload": context.payload,
        }
    )
    
    # Flag for review if from production project
    if context.project_uid == "proj_production":
        context.flag("Production dataset deleted - requires verification")
    else:
        context.skip()
```

### Export Failure Handler

```python
@agent.on("export.failed")
def on_export_failed(context):
    export_uid = context.resource_uid
    error_message = context.payload.get("error_message", "Unknown error")
    
    print(f"Export {export_uid} failed: {error_message}")
    
    # Flag for manual investigation
    context.flag(f"Export failed with error: {error_message}")
```

### Multi-Event Handler Pattern

```python
import requests

def notify_webhook(event_type: str, resource_uid: str, payload: dict):
    """Send event notification to external webhook."""
    requests.post(
        "https://example.com/webhook",
        json={
            "event": event_type,
            "resource": resource_uid,
            "data": payload,
        },
        timeout=10,
    )

@agent.on("dataset.created")
def on_dataset_created(context):
    notify_webhook(context.event_type, context.resource_uid, context.payload)
    context.skip()

@agent.on("dataset.updated")
def on_dataset_updated(context):
    notify_webhook(context.event_type, context.resource_uid, context.payload)
    context.skip()

@agent.on("export.completed")
def on_export_completed(context):
    notify_webhook(context.event_type, context.resource_uid, context.payload)
    context.skip()
```

### Conditional Processing

```python
@agent.on("dataset.updated")
def on_dataset_updated(context):
    # Only process updates from specific projects
    monitored_projects = ["proj_abc", "proj_def"]
    
    if context.project_uid not in monitored_projects:
        context.skip()
        return
    
    # Check what changed in the payload
    changes = context.payload.get("changes", {})
    
    if "schema" in changes:
        context.flag("Dataset schema changed - needs review")
    elif "metadata" in changes:
        context.approve("Metadata update approved")
    else:
        context.skip()
```
