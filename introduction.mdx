## Welcome to Avala Agents SDK

The Avala Agents SDK is a Python framework for building custom annotation workflow agents that integrate seamlessly with the [Avala](https://avala.ai) platform. Create intelligent quality control checks, automated validation logic, and custom workflow triggers using a simple, event-driven architecture.

## What can you build?

With the Avala Agents SDK, you can:

- **Automate quality control** — Validate annotation results in real-time and reject low-quality submissions
- **Enforce business rules** — Apply custom validation logic based on your domain requirements
- **Trigger workflows** — React to task completions, dataset changes, and export events
- **Flag for review** — Automatically flag edge cases and low-confidence annotations for human review

## Quick example

Here's a simple quality control agent that validates annotation results:

```python
from avala_agents import TaskAgent

agent = TaskAgent(
    api_key="avk_...",
    name="quality-checker",
    project="proj_uid",  # optional: scope to a single project
)

@agent.on("result.submitted")
def check_quality(context):
    annotations = context.result_data

    if len(annotations) == 0:
        context.reject("No annotations found")
    elif context.result_metadata.get("confidence", 1.0) < 0.5:
        context.flag("Low confidence — needs manual review")
    else:
        context.approve()

agent.run()  # blocks; polls for pending executions
```

## Requirements

- Python 3.9 or higher
- An Avala API key (obtain from your Avala dashboard)
- Basic familiarity with Python decorators and async/await patterns

<Note>
  The Avala Agents SDK is designed to be simple and intuitive. If you're familiar with event-driven programming in Python, you'll feel right at home.
</Note>
